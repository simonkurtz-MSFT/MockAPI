MockAPI is an open-source, self-hosted mock API server. Configure status codes, headers, and response bodies through the dashboard or a JSON file. Use it to test successful requests, rate limits, server errors, and connection failures. Endpoint changes take effect without a restart.

Getting started

Run your mock API locally or in a container

Recommended · Current source

Run locally

Install the stable .NET 10 SDK, then clone and run. No Node.js tooling is needed just to use MockAPI.

git clone https://github.com/simonkurtz-MSFT/MockAPI.git
cd MockAPI
PowerShell 7 
$env:ASPNETCORE_URLS = 'http://localhost:5080'
.\start.ps1 -Action run-tutorial
Bash 
export ASPNETCORE_URLS='http://localhost:5080'
./start.sh --action run-tutorial

Open localhost:5080/__mockapi/.

Bash

./start.sh --action container-run --container-engine docker

WSLC, persistence, and platform guide

Make your first request

  1. Open the dashboard and select Load examples.
  2. Configure dashboard administrator credentials, then generate a key in Settings > Mock API security.
  3. Select Test for /ex/hello, or send an external request with the X-MockAPI-Key header. Mock calls without a key return 401 by default.
  4. Edit the response, repeat the request, and check the response and request statistics.
  5. Select Save to keep changes in your configured writable file or volume.

Keep administration private. Localhost or a protected network is the default. Before sharing a deployment, configure administrative authentication and HTTPS.

Common uses

Mock API examples for development and testing

Develop against an unavailable API

Configure responses for an upstream API that is not yet available. Requests match an exact HTTP method and path, so your application can call the same routes during development.

Explore the built-in examples

Exercise retry behavior

Return HTTP 429 with Retry-After, configure server errors, or abort a connection. Check how your client handles these failures without changing the upstream service.

Keep test configuration in source control

Import and export endpoint definitions as JSON. Review configuration changes in source control or automate them through the management API.

Use the management API

Self-hosted, with a small runtime footprint

MockAPI runs as a single .NET application or Linux container. The dashboard is served by the application; no separate frontend server or hosted account is required. The runtime does not include analytics. This documentation page is not a running MockAPI instance.
