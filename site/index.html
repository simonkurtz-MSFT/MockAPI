Run locally

Install the stable .NET 10 SDK, then clone and run. No Node.js tooling is needed just to use MockAPI.

git clone https://github.com/simonkurtz-MSFT/MockAPI.git
cd MockAPI
PowerShell 7 
$env:ASPNETCORE_URLS = 'http://localhost:5080'
.\start.ps1 -Action run-tutorial
Bash 
export ASPNETCORE_URLS='http://localhost:5080'
./start.sh --action run-tutorial

Open localhost:5080/__mockapi/.

Use a container

Choose an existing version from Docker Hub. Published previews can lag behind this documentation; never assume an unpublished beta or a latest tag exists.

Browse published images

For current source, build with Docker:

PowerShell 7 
.\start.ps1 -Action container-build -ContainerEngine docker
.\start.ps1 -Action container-run -ContainerEngine docker
Bash 
./start.sh --action container-build --container-engine docker
./start.sh --action container-run --container-engine docker

WSLC, persistence, and platform guide

Make your first request

  1. Open the dashboard and select Load examples.
  2. Visit /ex/hello on your running MockAPI instance.
  3. Edit the response, call it again, and watch the statistics change.
  4. Select Save to keep changes in your configured writable file or volume.

Keep administration private. Localhost or a protected network is the default. Before sharing a deployment, configure administrative authentication and HTTPS.
